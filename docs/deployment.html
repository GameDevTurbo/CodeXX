CODEXX SERVER · v1.2.0

部署指南

下载软件 → 启动 Docker → 部署服务 → 登录账号 → 测试连接。预编译包无需 Python。

1下载软件

按系统选择一行。Server 解压使用；Docker 安装后打开。

系统CodeXX ServerDockerTailscale · 远程连接可选

Apple M 系列选 Apple 芯片版；Intel Mac 选 Intel 版。以上为当前提供的 Server 架构。完整 Release

2启动 Docker

打开 Docker Desktop，完成安装提示，等待引擎显示 Running。Linux 启动 Docker Engine，并确认 Compose 可用。

安装帮助与版本检查

macOS 安装说明 · Windows 安装说明（含 WSL）

docker version
docker compose version

第一条应包含 Server 信息，第二条应返回 Compose 版本。

需要跨设备访问：先在服务端和客户端安装 Tailscale，登录同一网络，完成系统授权。本机使用可跳过。

3打开 Server 并部署

系统解压后运行
macOSCLIProxyAPI-Server.app 或 Server.command
WindowsServer.bat
Linux 桌面./CLIProxyAPI-Server
  1. 点击 Setup。代理端口按实际配置填写，无代理填 0。
  2. 点击 Generate and Deploy，等待镜像下载与容器启动。
  3. 确认 Configuration 为 Ready、Service 为 Running。

macOS App 尚未签名公证，首次打开按系统允许的流程批准。已有配置会保留；新 GUI 配置优先绑定 Tailscale 地址，否则仅本机。

Linux 无桌面部署

在解压目录运行。默认仅本机访问；远程部署时，为初始化命令添加 --bind 服务端的Tailscale地址。

chmod +x CLIProxyAPI-Server
./CLIProxyAPI-Server --init --data-dir "$HOME/.local/share/CodeXX/Server"
cd "$HOME/.local/share/CodeXX/Server"
docker compose pull
docker compose up -d

如已设置 XDG_DATA_HOME 或使用自定义目录，后续命令使用同一数据目录。

4登录管理面板，接入账号

点击 Management Panel，使用管理密码登录，在面板中授权上游账号或填写上游 API Key。

打开本机管理面板

管理密码位于数据目录的 .credentials.json，字段为 mgmt_password。其中 api_keys 用于客户端请求。

数据目录在哪里？
macOS~/Library/Application Support/CodeXX/Server
Windows%LOCALAPPDATA%\CodeXX\Server
Linux~/.local/share/CodeXX/Server（或 XDG_DATA_HOME 下）

指定自定义目录或兼容旧配置时，以实际目录为准。macOS 在 Finder 按 ⌘⇧G 输入路径，按 ⌘⇧. 显示隐藏文件。

5连接客户端并测试

点击 Server 的“检查连接”，然后用兼容 OpenAI API 的客户端发送一次请求，确认收到模型回复。

基础地址http://localhost:8317/v1
API Key当前配置中的 api_keys
模型从服务返回的模型列表选择

可选用 CodeXX Client：

Windows 客户端macOS 客户端Linux 客户端版本与说明

模型列表可用不代表实际生成成功；测试请求可能消耗上游额度。

其他设备如何连接？

两端先连接同一 Tailscale 网络。使用 Server 的 Export .cliproxy 导出并导入客户端，或将基础地址改为 http://服务端Tailscale地址:8317/v1。服务必须已绑定该地址；远端不能使用 localhost。

既有配置不会自动改绑。若最初仅绑定本机，先备份并调整数据目录内 Compose 的端口绑定，再重新启动容器。

常见问题

Docker 未就绪打开 Docker，处理系统授权提示，等待引擎启动。
镜像下载卡住检查网络、Docker 代理和钥匙串提示，查看日志后再重试。
启动失败检查目录共享权限、8317 / 8085 端口占用与容器日志。
401 / 模型为空检查 API Key；确认上游账号授权及模型配置。

关闭管理窗口后服务仍会运行；停止服务请点击 Stop。升级前备份数据目录。
